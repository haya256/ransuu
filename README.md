# 乱数抽選機 RS-15 (ransuu)

指定した範囲の整数をランダムに1つ抽選する、演出重視のWebページです。
ニキシー管風の橙色に光る数字が約10秒かけて明滅・収束し、閃光とともに結果が確定します。

## 機能

- **抽選範囲**: 1 〜 N の整数(N はデフォルト15、2〜100 で変更可能)
- **約10秒の抽選演出**: 点火 → 走査(高速明滅から減速) → 消灯のタメ → 閃光・衝撃波・火の粉とともに確定
- **スキップ**: 抽選中にボタンまたは管をクリックで即確定
- **効果音**: WebAudio によるハム音・電子音・確定音(ON/OFF 切替可)
- **記録**: 抽選結果をタイムスタンプ付きで一覧表示。各行にメモ欄・完了チェック・削除ボタン付き
- **保存なし**: データはメモリ上のみ。リロードですべて消えます
- `prefers-reduced-motion` 設定時は演出を約1秒に短縮

## 使い方

`index.html` をブラウザで開くだけです。ビルドや依存関係はありません(HTML/CSS/JavaScript のみの単一ファイル)。
